# Simulador de Gestion de Productos - Pre-entrega 10

Simulador interactivo desarrollado en JavaScript para la gestion de productos e inventarios.

## Funcionalidades de la Pre-entrega 10
**Carga asincrona (Fetch API):** Lectura inicial de datos desde `./data/productos.json` con `async/await` y `try/catch`.
**Libreria externa (Toastify JS):** Notificaciones flotantes en tiempo real.
**Asincronismo (`setTimeout`):** Banner informativo ejecutado al ingresar al sitio.
**Manejo de errores (`try-catch-finally`):** Validacion de inputs en el formulario.
**Persistencia de datos:** Sincronizacion en tiempo real con `localStorage`.
